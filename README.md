# Free Play

Official games that open in the browser. Each Play button goes to the game's own site.

The page is static. GitHub Pages serves it from the repository root.

## Ads

Ads stay off until you add a publisher id. Open `ads.js` and set `client` to your AdSense id (`ca-pub-…`). Push that change, then in AdSense add the site `https://cybernze.github.io/free-play/` and turn on Auto ads.

## Images

The pictures in `images/` are the games' own preview images, saved so the page still works if their sites change the files. Each game links to the official page listed in `index.html`.
